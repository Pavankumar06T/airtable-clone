## 📌 About the Project

This is a full-stack Airtable Clone application built using the **MERN** stack (MongoDB, Express.js, React, Node.js).  
I developed this project to gain hands-on experience with dynamic form building, JWT-based user authentication, and MongoDB-based data modeling.

The goal was to allow users to:

- ✅ Register and log in securely
- ✅ Create dynamic tables with customizable fields (Text, Number, Dropdown, Date, etc.)
- ✅ Add and view records in those tables
- ✅ Ensure user-level data access with proper route protection

This project simulates the basics of a productivity tool like Airtable.

---

## 🔥 Features

- 🧾 User Registration & Login with JWT Authentication
- 🧩 Dynamic Table Creation (supports 10+ field types)
- 📝 Add records with dynamic forms based on field types
- 🔒 Authenticated Routes (only logged-in users can access their tables)
- 📊 View all records in table-wise format
- 🎯 Simple UI to keep it clean and understandable
